# Automated Valuation Model

A third-year university group project exploring machine-learning models for residential property valuation. This repository preserves the team's final report, including the modelling approach, website design, implementation discussion, and testing documentation.

**[Read the final group report](3rd_yr_team_report.pdf)**

## What the report covers

- Property-price estimation using US housing data.
- Comparisons of linear regression, neural networks, and random forests.
- A web interface for submitting property data and viewing valuation results.
- System requirements, prototype screens, implementation details, and a test report.
- Team reflections, project scheduling, and meeting records.

## Repository scope

The published artifact is the report dated April 23, 2020. Application source code, training data, and model files are not included, so this repository is a project record rather than a runnable valuation service.
